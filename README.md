# Apple Sales & Analytics Dashboard

An interactive Power BI dashboard designed to analyze sales performance, revenue streams, order volumes, profitability, and customer returns across Apple products.

## 📌 Overview
This project translates transactional data into actionable business insights, tracking critical KPIs, financial metrics, and operational performance to support data-driven retail and supply chain decisions.

## 📊 Key Metrics & Features
* **Revenue & Profitability**: Tracking Total Revenue, Net Profit, and Profit Margins across product categories.
* **Order & Volume Tracking**: Visualizing Total Orders, Completed Orders, Units Sold, and Average Order Value (AOV)[cite: 1].
* **Returns & Refunds**: Operational analytics monitor refund rates, return counts, and customer feedback metrics[cite: 1].
* **Target Tracking**: Custom visual indicators (including Bullet Charts) comparing current metrics against set targets[cite: 1].
